# GeminiDash Pro: AI Dataset Explorer & Chat 📊

An AI-driven data intelligence dashboard where users upload datasets and ask for business insights through natural-language chat.

## Technology
- Google Gemini API
- PHP and MySQL
- Chart.js
- Phosphor Icons

## Security note
Keep Gemini API credentials and database secrets in environment configuration, never in committed source files.

## Repository status
This repository is initialized with project documentation. The project source files are not included yet and can be added from the original project folder.
